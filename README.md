Datum Plot is the second app of the Datum family, after [Datum Plan](https://github.com/Edgar-Mendonca/Datum-Plan). It is being planned: the first version (0.1.0) will bring the application, automatic updates, an XY data table and a publication-style XY graph. See the [plan](docs/PLAN-0.1.md).
